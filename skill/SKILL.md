# 台灣統一發票對獎

## 這個技能能做什麼

1. **查中獎號碼**：列出目前資料庫內每一期的特別獎、特獎、頭獎號碼與領獎期間。
2. **比對單張發票**：輸入字軌號碼（10 碼含英文字母）或紙本發票的 8 碼數字，判斷是否中獎。
3. **讀發票照片**：解析「電子發票證明聯」左側 QR Code，取出字軌、開立日期、隨機碼、金額，再對獎。
4. **回報稅務與期限**：三獎以上扣 20% 所得稅、五獎以上 0.4% 印花稅、領獎截止倒數、打統編不得領獎。

## 何時**不要**用這個技能

- 使用者問的是**載具歸戶、手機條碼申請、獎金匯款設定** → 這是財政部電子發票整合服務平台的業務，本技能不處理。
- 使用者要**代領、代刷、代為兌換** → 一律說明需本人持證件臨櫃或透過官方 App 辦理。
- 使用者問**其他國家**的發票或收據對獎 → 不適用。

## 怎麼執行

本技能附一支命令列工具（同時是本機網頁 App 與 MCP server）：

```bash
# 對獎（10 碼字軌）
twiv check AB12345678 --period 11504

# 對獎（紙本 8 碼，未指定期別時用最新一期）
twiv check 89996565

# 用發票照片對獎
twiv scan ./receipt.jpg

# 只看 QR 原始內容（除錯）
twiv qr ./receipt.jpg

# 目前資料版本與各期號碼
twiv status --json
```

所有指令都支援 `--json`，輸出為機器可讀格式，適合再由你整理成自然語言回答。

## 回覆使用者時的原則

- **先講結論**：中獎 → 講獎別與金額；未中獎 → 直接說未中獎，不要含糊。
- **一定要提領獎期限**：逾期不得領獎，這是最容易讓使用者吃虧的地方。
- **中獎時提醒稅務**：三獎（含）以上扣 20% 所得稅；五獎及雲端 500 元以上 0.4% 印花稅
  （已在電子發票平台設定領獎帳戶者免繳）。
- **打了統編要提醒**：買受人為營業人的發票不得領獎。
- **不要編造號碼**：所有號碼必須來自工具輸出，禁止憑印象回答。
- **不要保證一定領得到**：實際兌領以財政部公告與代發獎金單位為準。

## 資料來源與更新

- 一般獎別：`https://invoice.etax.nat.gov.tw/index.html`（當期）、`lastNumber.html`（上一期）
- 雲端發票專屬獎：`cloudNowNumber.html` 上的 PDF 清單（每期數百萬筆）

每兩個月開獎一次（單月 25 日）。要更新資料執行 `twiv fetch`，或在本機 App 按「檢查並更新」。

## 名詞對照

| 中文 | 說明 |
|---|---|
| 期別 | 每兩個月一期，代碼如 `11504` = 民國 115 年 07-08 月 |
| 字軌號碼 | 2 碼英文 + 8 碼數字，例如 `AB12345678` |
| 特別獎 | 8 碼全中，1,000 萬元 |
| 特獎 | 8 碼全中，200 萬元 |
| 頭獎 | 8 碼全中（每期 3 組），20 萬元 |
| 二獎～六獎 | 對中頭獎號碼的末 7／6／5／4／3 碼 |
| 雲端發票專屬獎 | 只有雲端發票（未列印紙本）才有的加碼獎 |
