# 資料來源

## 官方頁面（一般獎別）

| 用途 | 網址 |
|---|---|
| 當期中獎號碼單 | `https://invoice.etax.nat.gov.tw/index.html` |
| 上一期中獎號碼單 | `https://invoice.etax.nat.gov.tw/lastNumber.html` |
| 特別獎／特獎中獎清冊 | `index.html` 上的 `list1.html`、`list2.html` |

**特性**：靜態 HTML、無 JavaScript、無需登入、無 API key。

**頁面結構**：

```html
<tr><td>特別獎</td><td>89996565<br>同期統一發票收執聯8位數號碼與特別獎號碼相同者獎金1,000萬元</td></tr>
<tr><td>頭獎</td><td>54348835<br> 44991397<br> 06595111<br>...</td></tr>
```

**陷阱**：`lastNumber.html` 的導覽列同時列出「當期」與「上一期」兩個標題。
只取第一個符合 `NNN年MM-MM月` 的字串會抓錯期別。
本專案用「`href` 等於本頁檔名」定位（`parse_period_title_for`），
再用「官方寫的領獎期間」與「自己推算的領獎期間」交叉驗證，不符就中止。

## 雲端發票專屬獎（PDF）

`https://invoice.etax.nat.gov.tw/cloudNowNumber.html` 上有 8 個 PDF 連結
（4 個獎級 × 已排序／依開獎順序）。檔名格式：

```
pdf/{西元年}{起月}{迄月}_{timestamp}_[sorted_]AI_{獎級}.pdf
     └ 20260708 = 2026 年 07-08 月期
```

| 檔名代碼 | 獎級 | 實測筆數 | 實測大小 |
|---|---|---|---|
| `AI_C` | 百萬元獎 | 30 | 75 KB |
| `AI_B` | 兩千元獎 | 約 1.6 萬 | — |
| `AI_E` | 八百元獎 | **100,000** | 3.2 MB |
| `AI_D` | 五百元獎 | **4,350,000** | **128.9 MB** |

**為什麼只下載 `_sorted_` 版本**：建立差分索引本來就需要排序；
未排序版本檔案一樣大，卻不能直接用。

**解析方式**：這些 PDF 是**文字型**（非掃描影像），所以不需要 OCR。
`invoice-scrape::pdf` 會解開 `/FlateDecode` 內容流，取出所有字串運算元
（`(...)Tj`、`[(..)-2(..)]TJ`、`<hex>`），串接後掃描 `[A-Z]{2}\d{8}`。

實測：128.9 MB PDF → 抽出 435 萬筆，耗時約 20 秒。

## 開獎節奏

- 每兩個月一期，全年六期（01-02、03-04、05-06、07-08、09-10、11-12 月）
- 開獎日：該期結束月的次月 25 日
- 領獎期間：開獎日次月 6 日起三個月

以 115 年 07-08 月期為例：

```
期別      11504
開獎日    2026-09-25
領獎期間  2026-10-06 ~ 2027-01-05
```

## 稅務與限制

- 三獎（含）以上：扣繳 **20% 所得稅**
- 五獎及雲端 500 元以上：**0.4% 印花稅**（已於電子發票平台設定領獎帳戶者免繳）
- 買受人為政府機關、公營事業、公立學校、部隊及**營業人（打統編）**者，不得領獎
- 未依規定載明金額者，不得領獎
- 逾期不得領獎

## 抓取禮儀

- 每期只需抓一次（開獎後）
- 本專案內建 3 次重試與 600ms 遞增退避
- 不要併發打官方站台；`fetch_cloud_index` 是循序下載
- 資料屬政府公開資訊，但仍請保留來源標註
